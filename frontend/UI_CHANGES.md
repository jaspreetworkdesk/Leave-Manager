# Responsive UI update

This package keeps the existing business and API logic while modernizing the provided frontend files.

## Main updates

- Responsive mobile, tablet, laptop, and desktop dashboard shell
- Slide-out mobile sidebar with overlay and touch-friendly navigation
- Sticky dashboard header with user identity and role
- Modern login, forgot-password, and reset-password layouts
- Shared design tokens, spacing, shadows, focus states, and reduced-motion support
- Consistent form inputs, selects, textareas, buttons, cards, and validation messages
- Responsive table containers with horizontal scrolling on small screens
- Updated statistics cards, pagination controls, empty states, and leave-details modal
- Improved semantic labels, focus behavior, and basic accessibility attributes

## Integration

Copy these files over the matching frontend files in the full project, then run:

```bash
npm ci
npm run build
```

The uploaded archive did not include the full project configuration, services, or package files, so a complete application build could not be executed in this isolated package.
